# SYLION Admin Panel V2

V2 zaczyna się po zamrożeniu V1.

V1 dostarczyło:

```text
in-memory Admin API
20 modułów domenowych
minimalny statyczny Admin Shell
pełny human-flow E2E
23 testy passing
```

V2 ma przekształcić prototyp domenowy w używalną aplikację operacyjną.
