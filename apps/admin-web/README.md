# SYLION Admin Web

Minimalny statyczny Admin Shell dla etapu V1.

Uruchomienie bez bundlera:

```text
otwórz apps/admin-web/index.html w przeglądarce
```

Panel jest na tym etapie statycznym shell UI pokazującym moduły, statusy i pierwsze flow operacyjne. Pełna integracja z Admin API zostanie dołożona w kolejnym etapie.
