# SYLION Admin Panel V2

V2 zaczyna sie po zamrozeniu V1.

V1 dostarczylo:

```text
in-memory Admin API
20 modulow domenowych
minimalny statyczny Admin Shell
pelny human-flow E2E
23 testy passing
```

V2 przeksztalca prototyp domenowy w uzywalna aplikacje operacyjna.
